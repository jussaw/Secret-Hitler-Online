# Phase 11: Lobby redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the lobby page to match the Phase 8 game screen, fit one screen, explain what
START GAME is waiting for, and let anyone in the lobby switch between playing and watching
(issue #23).

**Architecture:** A new `src/lobby/` folder holds the lobby page (`LobbyScreen`), its roster
(`LobbyRoster`, built on a row component shared with the game's `PlayerRoster`), and pure helpers
for the status line, join errors and copying. `App` keeps the sockets: WATCH INSTEAD and PLAY
INSTEAD reopen the WebSocket as the other kind through the existing `tryOpenWebSocket`, which
already detaches the old socket's close handler. One backend change: a game seats only players with
a live connection.

**Tech Stack:** React 18, TypeScript 5, Vite, Vitest with Testing Library, `@playwright/test`,
`lucide-react` (already a dependency) · Java 17, Javalin 5, JUnit 4.

**Spec:** [`docs/superpowers/specs/2026-11-13-lobby-redesign-design.md`](../specs/2026-11-13-lobby-redesign-design.md),
with the mockup screenshots in [`2026-11-13-lobby-redesign/`](../specs/2026-11-13-lobby-redesign/).
Parent plan: [`docs/PLAN.md`](../../PLAN.md), Phase 11.

## Decisions (the user, 2026-11-13)

1. **Layout A**, the game's split: roster column on the left on desktop, the game's tall and phone
   layouts otherwise. Phones put the roster first.
2. **The switch is offered in the lobby only.**
3. **The switch reconnects in the browser.** No protocol change.
4. **A spectator switches with a PLAY INSTEAD button and a name prompt**, not a field on the page.
5. **Fix the game-start seat bug here** (a backend change): a game seats only connected players.

## Review Focus

1. **A spectator in a lobby with no players** (everyone left): the line reads `You are watching.
   No one has a seat yet.`, PLAY INSTEAD is on, nothing throws. Task 3 and Task 5 test it.
2. **The host starts the game while a spectator's PLAY INSTEAD prompt is open:** the prompt closes
   and they watch the game. Task 7 tests it.
3. **CONTINUE pressed twice** (or Enter, then a click): one check, one socket. CONTINUE is disabled
   while the check runs. Task 6 tests it.
4. **An empty or all-space name:** CONTINUE stays disabled, and the name sent is trimmed. Task 6
   tests it.
5. **A player who comes back after a game started without them** (they were inside the grace
   window at the start): they cannot take a seat and can watch. Task 1 tests `canRejoin`.
